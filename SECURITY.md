# Security policy

## Supported versions

Security fixes are applied to the latest released version of CapyBite.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email [service.help@outlook.kr](mailto:service.help@outlook.kr) with:

- a clear description of the issue;
- affected versions and macOS version;
- reproduction steps or a minimal proof of concept;
- the possible impact;
- any suggested remediation.

Do not access data that does not belong to you, disrupt the service, or publish details before a fix is available. You should receive an initial response within seven days.
